Primeros pasos

Cómo instalar

Android

  1. Descarga el archivo .apk.
  2. Abre el archivo y permite instalar desde esta fuente si el sistema lo solicita.
  3. Listo: inicia sesión o crea tu cuenta.

Linux

  1. Descarga el archivo .tar.gz.
  2. Extrae el contenido en una carpeta.
  3. Ejecuta el binario ./mercado.

Windows

  1. Descarga y descomprime el archivo .zip.
  2. Ejecuta mercado.exe.
  3. Si SmartScreen muestra una advertencia, elige “Más información” y luego “Ejecutar de todas formas”.
